# Project Conventions — ABAP Lessons

## Lesson file conventions
- Each lesson gets TWO files:
  - `NNN_LessonName.md` — tutorial with theory first, then code, then practice
  - `NNN_LessonName.abap` — runnable ABAP source
- HTML version of each lesson goes in the `HTML_Version/` folder as `NNN_LessonName.html`
- Lesson numbering: sequential, e.g. 001, 002, 003...
